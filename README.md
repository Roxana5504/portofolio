# Roxana Portfolio V6 — Where to find me

This is the complete website, with all files in **one folder**. Upload the contents to the root of your GitHub repository for the existing Render site.

## This revision
- Added a responsive `Where to find me` section before the existing contact area, with linked Instagram, Facebook, LinkedIn and Upwork cards using local vector brand icons.
- Removed the old Instagram, Facebook and LinkedIn links from the contact area; kept `Back to top`.
- All image and logo references use root-relative file names (no subfolder needed).
- No other design, content, campaigns or project functionality was altered.

Render start command: `npm start`.

Brand icons are from Font Awesome Free 6.7.2, `@fortawesome/fontawesome-free` (Brands, CC BY 4.0), with attribution retained in each SVG.
